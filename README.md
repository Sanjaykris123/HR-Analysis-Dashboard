# HR-Analysis-Dashboard
Project Overview
This project is an HR Analysis Dashboard created using Microsoft Excel to analyze employee data and provide useful insights into workforce performance and employee demographics.
Tools Used
* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Excel Formulas
* Data Cleaning
* Dashboard & Data Visualization
Key Analysis
* Employee Headcount
* Employee Attrition
* Department-wise Employees
* Gender-wise Employee Distribution
* Age-wise Employee Analysis
* Job Role Analysis
* Salary Analysis
* Employee Performance
Project Description:
Developed an interactive  HR Analytics Dashboard in Microsoft Excel to analyze employee demographics, attrition trends, and workforce performance. Used data cleaning, Pivot Tables, Pivot Charts, KPIs, slicers, and interactive visualizations to generate actionable HR insights.
